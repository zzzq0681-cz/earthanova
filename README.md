# Earth Sentinel — MVP Concept

**Tagline:** Explore Earth. Detect Change. Understand What Comes Next.

**Type:** Interactive web concept / clickable MVP demo  
**Presentation length:** 10 minutes maximum  
**Deadline:** Tomorrow  
**Language:** UI in English; presentation notes can be Arabic  
**Important:** All displayed numbers are **simulated demo data**, not live NASA measurements.

## The idea in 30 seconds
Earth Sentinel is an interactive Earth intelligence concept. The user rotates a 3D globe, clicks a city or any location, views a location popup, and starts an animated scan. A simple dashboard then explains environmental changes through a *Before vs After* comparison, a trend finding, a 5-year **illustrative scenario**, and four virtual monitoring stations. The goal is to show an understandable discovery journey—not to ship a production scientific platform.

## One sentence to say on stage
> “With one click on Earth, we turn complex environmental change into a visual story that anyone can understand.”

## Demo boundaries
- One browser experience, optimized for desktop presentation.
- **One featured story:** Alexandria, Egypt. Other selectable locations may reuse generated demo cases.
- No real signup, billing, live notifications, live satellite analytics, or production backend.
- No unverified claims such as “live,” “scientifically significant,” or “safe for investment” based on synthetic data.

## Definition of a successful demo
The presenter opens the app, rotates Earth, selects Alexandria, sees the location popup, clicks **Scan Area**, waits for a short animated scan, and shows linked cards for Before/After, key changes, a forecast scenario, and monitoring indicators. Everything responds smoothly, using consistent simulated data. The complete story takes less than 4 minutes of live clicking.
